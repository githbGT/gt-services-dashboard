# דשבורד קטלוג השירותים העירוני – גני תקווה

דשבורד ציבורי אינטראקטיבי שנבנה מקטלוג השירותים העירוני ומוטמע באתר העירייה באמצעות iframe.
התוצר הוא קובץ HTML אחד ועצמאי (`docs/index.html`), בלי פניות לשרתים חיצוניים.

## איך זה עובד

```
קטלוג השירותים (Excel, ב-SharePoint)
        │  python update.py
        ▼
data/public_catalog.csv    ← הנתונים שמתפרסמים, נשמרים ב-Git
        │
        ▼
docs/index.html            ← הדשבורד, נשמר ב-Git ומועלה לאתר
```

קובץ האקסל נקרא בלבד ולא משתנה. הוא לא נשמר בריפו (ראו `.gitignore`), כי מקור האמת שלו הוא SharePoint.
קובץ ה-CSV מראה בדיוק מה מתפרסם, ו-Git מציג בו שינויים שורה אחרי שורה.

## מבנה הריפו

| נתיב | תפקיד |
|---|---|
| `update.py` | מריץ את שני השלבים. זו הפקודה היחידה שצריך |
| `config.py` | כל ההגדרות: נתיב לקטלוג, טקסטים, שמות עמודות, מיפוי ערכים |
| `src/extract.py` | שלב 1: קטלוג ← CSV, כולל ניקוי ובדיקות |
| `src/build.py` | שלב 2: CSV ← HTML |
| `templates/dashboard.html` | העיצוב וההתנהגות של הדשבורד |
| `assets/` | ספריית הגרפים (Plotly basic) והלוגו. נארזים לתוך ה-HTML |
| `data/public_catalog.csv` | הנתונים הציבוריים (נוצר אוטומטית) |
| `docs/index.html` | הדשבורד (נוצר אוטומטית) |
| `examples/embed-example.html` | קוד הטמעה לאתר העירוני |

## התקנה (פעם אחת)

```
pip install -r requirements.txt
```

ב-`config.py` מגדירים את `CATALOG_PATH` לנתיב של קובץ הקטלוג במחשב.
הכי נוח: הנתיב של התיקייה המסונכרנת מ-SharePoint ב-OneDrive, כך שתמיד נקראת הגרסה העדכנית.

## עדכון הדשבורד

1. מעדכנים את הקטלוג באקסל ושומרים.
2. מריצים:
   ```
   python update.py
   ```
   או עם נתיב אחר: `python update.py "C:\...\קטלוג שירותים.xlsx"`
3. פותחים את `docs/index.html` בדפדפן ובודקים.
4. `git add . && git commit -m "עדכון קטלוג" && git push`
5. מעלים את `docs/index.html` לאתר, לאותה כתובת. ה-iframe לא משתנה.

### מה קורה כשמוסיפים או משנים שירות

- **שורה חדשה** נקלטת אוטומטית, גם בתוך הטבלה וגם מתחתיה. הסקריפט קורא כל שורה שיש בה שם שירות.
  (בדשבורד האקסל הישן הנוסחאות היו מקובעות לשורות 3–114, כך ששורה 115 לא הייתה נספרת שם.)
- **ערך חדש** בקהל יעד או בסוג שירות מופיע בדשבורד כמו שהוא, והסקריפט מדפיס הודעה.
  אם רוצים שם מקוצר לתצוגה, מוסיפים אותו ל-`AUDIENCE_MAP` ב-`config.py`.
- **שינוי שם עמודה** קטן (רווחים, כוכבית) לא מפריע. שינוי משמעותי יעצור את הריצה עם הודעה ברורה,
  ומעדכנים את השם ב-`COLUMNS` ב-`config.py`.
- **שורה ריקה** או שורה בלי שם שירות מדולגת.
- הסקריפט מדפיס הערות על בעיות בנתונים (ערך חסר, רמה לא מזוהה, פילוח ערוצים שלא מסתכם). הן לא עוצרות את הריצה.

התאריך בתחתית הדשבורד מתעדכן אוטומטית לחודש שבו נבנה. אפשר לקבע אותו ב-`UPDATE_DATE`.

## הטמעה באתר

ראו `examples/embed-example.html`. הדשבורד שולח לדף המארח את הגובה שלו, והסקריפט בדוגמה
מתאים את גובה ה-iframe כך שלא יופיע פס גלילה פנימי. הגובה משתנה בזמן סינון, וה-iframe מתעדכן בהתאם.
אם מערכת האתר לא מאפשרת סקריפט, אפשר iframe עם גובה קבוע (כ-2900px במחשב, כ-5200px בטלפון).

**אירוח ב-GitHub Pages (אופציונלי):** הקובץ נמצא בתיקיית `docs`, ולכן אפשר להפעיל
Settings ← Pages ← Deploy from branch ← `main` / `docs`. בחשבון GitHub חינמי זה דורש ריפו ציבורי.

## מה אפשר לעשות בדשבורד

- **סינון** לפי קהל יעד וסוג שירות, מהתפריטים או בלחיצה על הגרפים עצמם.
  כל הגרפים, המדדים והרשימה מתעדכנים. כל גרף מתעלם מהסינון של עצמו ומדגיש את הבחירה, כדי שאפשר יהיה להשוות.
- **עשרת השירותים הנפוצים:** לחיצה על שירות פותחת את דף השירות.
- **רשימת כל השירותים** עם חיפוש, דרכי קבלת השירות (מקוון, טלפון, דואר אלקטרוני, פרונטלי, דואר, עמדת שירות) וקישור לדף השירות.
  התוויות וסדר ההצגה מוגדרים ב-`CHANNEL_LABELS` ב-`config.py`.
- **עיצוב:** גופן Arial וצבעי הלוגו של גני תקווה. הצבעים מוגדרים בראש `templates/dashboard.html`.
- **נגישות:** כל גרף זמין גם כטבלה, הכול עובד במקלדת, ויש התאמה למובייל.
